
# Vellum

[Vellum](https://jacobgassert092.github.io/Vellum/) is a work in progress, passion project, dedicated to making translation easier and more enjoyable.

<img width="2439" height="655" alt="image" src="https://github.com/user-attachments/assets/014c837b-8593-48b8-8640-d657d8e99a3d" />

Vellum is a translation tool, made to make hand translating much more convenient and efficient, being web-based it allows the use of tools such as yomitan and other pop-up dictionaries. The core gimmick of Vellum is the ability to read and translate at the same time, with built-in tooling allowing it to feel more natural than just splitscreening a novel on one tab and google docs in the other, Such as:

<br><br>

* Smart Sentence Highlighting
  * Underline and Highlight current sentence that corresponds to what you are actively translating.
  * Highlight already translated sentences to make naviagtion easier. 
* Progress Tracking
* Export Translations 
* More to Come
